# Installation

## Requirements

- Unity 2022.3 or later
- Unity Test Framework 1.1.33
- PlayerPrefs Manager key enumeration currently supports Windows Editor

## Install Latest Version

Open Unity Package Manager:

```text
Window > Package Manager
```

Select:

```text
+ > Add package from git URL...
```

Enter:

```text
https://github.com/oort-games/oort-unity.git
```

## Install a Specific Version

To install a specific release, append the release tag to the Git URL.

Example:

```text
https://github.com/oort-games/oort-unity.git#v0.0.2
```

## Samples

Oort Unity samples are distributed through the package `Samples~` directory and can be imported from Unity Package Manager.

1. Open Package Manager.
2. Select **Oort Unity**.
3. Open the **Samples** section.
4. Import **Basic Sample**.
